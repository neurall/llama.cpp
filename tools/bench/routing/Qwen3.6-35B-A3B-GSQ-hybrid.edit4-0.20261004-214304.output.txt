Here is the function to count the lines of the file and print the count. You can add this to your `main.cpp` or a separate utility file.

```cpp
#include <iostream>
#include <fstream>
#include <string>

void count_and_print_lines(const std::string& filename) {
    std::ifstream file(filename);
    if (!file.is_open()) {
        std::cerr << "Error: Could not open file '" << filename << "'\n";
        return;
    }

    int line_count = 0;
    std::string line;
    while (std::getline(file, line)) {
        line_count++;
    }

    std::cout << "Total lines in '" << filename << "': " << line_count << "\n";
}

// Example usage in main:
int main() {
    count_and_print_lines("common/json-schema-to-grammar.cpp");
    return 0;
}
```

### Notes:
1. **Blank Lines**: This counts all lines, including blank lines and comments.
2. **File Path**: Ensure the path `"common/json-schema-to-grammar.cpp"` is correct relative to where you run the program.
3. **Encoding**: `std::getline` handles UTF-8 correctly in most modern C++ environments, but if your file contains non-standard encodings, you might need to adjust accordingly.

### To integrate into your existing code:
If you want to add this directly to the existing file (though not recommended for production code), you can append it at the end. However, it's better to keep it in a separate utility file or `main.cpp`.

### Alternative: Using `wc` (Unix/Linux)
If you're on a Unix/Linux system, you can simply run:
```bash
wc -l common/json-schema-to-grammar.cpp
```
This will output the line count directly.
