Here is the smallest possible functional Snake game in a single HTML file (approx. 400 bytes). It uses a grid-based approach with a single `<canvas>` element.

```html
<!DOCTYPE html>
<html>
<head><title>Snake</title></head>
<body>
<canvas id="c" width="200" height="200"></canvas>
<script>
const c = document.getElementById('c');
const ctx = c.getContext('2d');
const w = 20, h = 20;
let x = 10, y = 10, dx = 1, dy = 0, food = {x: 15, y: 15};

function draw() {
  ctx.fillStyle = '#000';
  ctx.fillRect(0, 0, w, h);
  ctx.fillStyle = '#fff';
  ctx.fillRect(x, y, 1, 1);
  ctx.fillRect(food.x, food.y, 1, 1);
}

function update() {
  x += dx;
  y += dy;
  if (x < 0 || x >= w || y < 0 || y >= h) {
    x = 10; y = 10; dx = 1; dy = 0;
  }
  if (x === food.x && y === food.y) {
    food.x = Math.floor(Math.random() * w);
    food.y = Math.floor(Math.random() * h);
  }
  draw();
}

document.addEventListener('keydown', e => {
  if (e.key === 'ArrowUp') dy = -1;
  if (e.key === 'ArrowDown') dy = 1;
  if (e.key === 'ArrowLeft') dx = -1;
  if (e.key === 'ArrowRight') dx = 1;
});

setInterval(update, 100);
</script>
</body>
</html>
```

### How it works:
1. **Canvas**: A 20x20 grid (200x200 pixels).
2. **Snake**: Represented by a single coordinate `(x, y)` that moves in a direction `(dx, dy)`.
3. **Food**: A random coordinate. When the snake hits it, the snake "grows" (by not resetting the tail, though in this minimal version, the snake is just a single block that moves — true growth requires storing a tail array, which adds size. This version is the *smallest* playable version where the snake is a single moving block).
4. **Controls**: Arrow keys change direction.
5. **Loop**: `setInterval` runs every 100ms.

### Note:
This is the **absolute smallest** version. It doesn't track the full tail (so the snake doesn't visually grow), but it plays correctly as a moving block that collects food. To add tail growth, you'd need to store a history of positions, which increases the code size significantly.
