### 🔹 Part 3: Integration by Parts in General

Integration by parts is a technique derived from the **product rule for differentiation**:
$$\frac{d}{dx}(uv) = u \frac{dv}{dx} + v \frac{du}{dx}$$
Integrate both sides with respect to $x$:
$$uv = \int u \, dv + \int v \, du$$
Rearrange to isolate the integral:
$$\int u \, dv = uv - \int v \, du$$

**When to use it:**
- The integrand is a product of two functions.
- One function simplifies dramatically when differentiated (e.g., polynomials, logarithms).
- The other function is easy to integrate (e.g., exponentials, trigonometric functions).
- It's especially powerful for repeated applications (like $x^n e^x$, $x^n \sin x$, etc.).

---
### 🔹 Part 4: How to Choose Which Factor to Differentiate

A widely used heuristic is the **LIATE Rule**. It ranks function types by order of preference for $u$ (the part you differentiate):

| Letter | Function Type          | Example                  |
|--------|------------------------|--------------------------|
| **L**  | Logarithmic            | $\ln x$, $\ln(x^2)$      |
| **I**  | Inverse Trigonometric  | $\arcsin x$, $\arctan x$ |
| **A**  | Algebraic (Polynomials)| $x^2$, $x^3$, $5x+1$     |
| **T**  | Trigonometric          | $\sin x$, $\cos x$       |
| **E**  | Exponential            | $e^x$, $2^x$             |

**Rule:** Choose $u$ from the function that appears **earlier** in LIATE, and $dv$ from the one that appears **later**.

**Why this works:**
- Differentiating earlier types simplifies them (polynomials drop degree, logs become rational, inverse trig functions become algebraic).
- Integrating later types is straightforward or cycles predictably (exponentials stay exponential, trig functions cycle).

**Examples:**
1. $\int x^2 e^x \, dx$ → $u = x^2$ (A), $dv = e^x dx$ (E) ✅
2. $\int x \ln x \, dx$ → $u = \ln x$ (L), $dv = x dx$ (A) ✅
3. $\int e^x \sin x \, dx$ → $u = \sin x$ (T), $dv = e^x dx$ (E) ✅ (Note: T comes before E)

**Important Caveats:**
- LIATE is a **guideline**, not a strict law. Sometimes you must reverse it if the integral of the "later" function is problematic or if repeated integration by parts is needed.
- For repeated applications (e.g., $\int x^3 e^x dx$), the **tabular method** (DI method) is faster: alternate signs and derivatives/integrations in a table until $u$ becomes 0.
