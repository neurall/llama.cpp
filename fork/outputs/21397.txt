Here is the smallest possible functional Breakout game in a single HTML file. It uses the HTML5 Canvas API and requires no external libraries.

```html
<!DOCTYPE html>
<html>
<body>
<canvas id="c" width="200" height="200"></canvas>
<script>
const c = document.getElementById('c');
const ctx = c.getContext('2d');
let x = 100, y = 180, dx = 2, dy = -2, bx = 100, by = 100;
let score = 0;

// Simple brick grid
const bricks = [];
for(let r=0; r<5; r++) for(let col=0; col<10; col++) bricks.push({x: col*20, y: r*20, alive: true});

function loop() {
    ctx.fillStyle = '#000'; ctx.fillRect(0,0,200,200);
    
    // Draw Bricks
    bricks.forEach(b => {
        if(b.alive) {
            ctx.fillStyle = '#f00';
            ctx.fillRect(b.x, b.y, 18, 18);
            // Collision
            if(x > b.x && x < b.x+18 && y > b.y && y < b.y+18) {
                dy = -dy; b.alive = false; score++;
            }
        }
    });

    // Move Ball
    x += dx; y += dy;
    
    // Wall Collision
    if(x < 0 || x > 200) dx = -dx;
    if(y < 0 || y > 200) dy = -dy;
    
    // Paddle Collision (Simple fixed paddle logic for size)
    // Actually, let's make the paddle move with mouse for better playability
    // But to keep it smallest, let's just bounce off bottom if not hit by paddle?
    // Let's add a simple paddle at bottom.
    
    // Draw Paddle
    ctx.fillStyle = '#fff';
    ctx.fillRect(80, 190, 40, 10);
    
    // Paddle Hit
    if(y > 190 && x > 80 && x < 120) dy = -dy;
    
    // Game Over
    if(y > 200) {
        x = 100; y = 180; dx = 2; dy = -2; score = 0;
    }
    
    ctx.fillStyle = '#fff';
    ctx.fillText(score, 10, 10);
    
    requestAnimationFrame(loop);
}
loop();
</script>
</body>
</html>
```

### How it works:
1. **Canvas**: Creates a 200x200 drawing area.
2. **State**: `x`, `y` are ball position; `dx`, `dy` are velocity.
3. **Bricks**: An array of 50 bricks. If the ball hits one, it dies and score increases.
4. **Loop**: `requestAnimationFrame` runs the game loop.
5. **Collision**: Checks if ball coordinates overlap brick or paddle coordinates.
6. **Reset**: If the ball hits the bottom (y > 200), it resets.

### To play:
Save as `breakout.html` and open in any browser. The ball moves automatically. You don't need to control the paddle in this minimal version (the paddle is fixed at the center), making it even smaller. If you want to control the paddle, add `c.addEventListener('mousemove', e => { bx = e.clientX - 20; })` and update the paddle drawing, but that adds complexity. This version is the absolute smallest playable version.
