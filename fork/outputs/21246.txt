3.  **Design the LRU Cache:**
   - Class `LRUCache`:
     - `__init__(self, capacity: int)`
     - `get(self, key: int) -> int`: Returns value if exists, else -1. If exists, mark as recently used.
     - `put(self, key: int, value: int) -> None`: If key exists, update value and mark as recently used. If not, add new key-value. If capacity exceeded, evict LRU.
   - Data structures:
     - `self.cache`: dict mapping key to node (or just value, but we need to track order). Actually, dict maps key to node in the linked list.
     - `self.head` and `self.tail`: sentinel nodes for the doubly-linked list.
     - Each node: `key`, `value`, `prev`, `next`.
   - Operations:
     - `add_node(node)`: Add to end of list (after tail).
     - `remove_node(node)`: Remove from list.
     - Both are O(1) with doubly-linked list.
     - `get`: Check dict. If exists, move node to end (O(1)), return value. Else return -1.
     - `put`: Check dict. If exists, update value, move to end. Else, create new node, add to dict, add to list. If len > capacity, remove head node (LRU), delete from dict.

4.  **Draft Code (Mental Refinement):**
   ```python
   class Node:
       def __init__(self, key=0, val=0):
           self.key = key
           self.val = val
           self.prev = None
           self.next = None

   class LRUCache:
       def __init__(self, capacity: int):
           self.capacity = capacity
           self.cache = {}
           self.head = Node()
           self.tail = Node()
           self.head.next = self.tail
           self.tail.prev = self.head

       def _add(self, node):
           # Add node to the end (before tail)
           prev = self.tail.prev
           prev.next = node
           node.prev = prev
           node.next = self.tail
           self.tail.prev = node

       def _remove(self, node):
           # Remove node from list
           prev = node.prev
           nxt = node.next
           prev.next = nxt
           nxt.prev = prev

       def get(self, key: int) -> int:
           if key not in self.cache:
               return -1
           node = self.cache[key]
           self._remove(node)
           self._add(node)
           return node.val
