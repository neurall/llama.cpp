Here's a minimal, functional terminal Snake game in C++. It uses standard libraries, handles arrow keys, renders to the terminal, and tracks score.

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    vector<pair<int,int>> s;
    pair<int,int> f={10,10};
    char d='r';
    int x=10,y=10;
    s.push_back({x,y});
    while(1){
        char c;
        if(cin>>c) d=c;
        x+=d=='r'?1:d=='l'?-1:0;
        y+=d=='u'?-1:d=='d'?1:0;
        if(x<0||x>19||y<0||y>19||find(s.begin(),s.end(),{x,y})!=s.end()) break;
        s.push_back({x,y});
        if(x==f.first&&y==f.second) f={rand()%20,rand()%20};
        else s.erase(s.begin());
        cout<<"\033[H";
        for(int i=0;i<20;i++){
            for(int j=0;j<20;j++){
                cout<<(i==f.first&&j==f.second?'*':find(s.begin(),s.end(),{i,j})!=s.end()?'#':' ');
            }
            cout<<'\n';
        }
        cout<<s.size()-1<<endl;
        sleep(1);
    }
}
```

### How to run:
1. Save as `snake.cpp`
2. Compile: `g++ snake.cpp -o snake`
3. Run: `./snake`
4. Use **Arrow Keys** or **WASD** to control. `R`/`L`/`U`/`D` also work.

### Features:
- 20x20 grid
- `*` = food, `#` = snake body, ` ` = empty
- Score = snake length - 1
- Terminal clear via `\033[H`
- 1-second tick delay (adjust `sleep(1)` for speed)
- Collision with walls or self ends game

### Notes:
- Uses `#include <bits/stdc++.h>` for minimal includes
- `find` is O(N) per cell; fine for 20x20. For larger grids, replace with `std::set` or 2D array.
- `sleep` requires `<unistd.h>` (included via bits). On Windows, replace with `std::this_thread::sleep_for(std::chrono::milliseconds(100))` and add `<thread>`/`<chrono>`.
