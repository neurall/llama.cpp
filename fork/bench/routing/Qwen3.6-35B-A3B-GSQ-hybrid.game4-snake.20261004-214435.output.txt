Here's the smallest complete HTML Snake game:

```html
<!DOCTYPE html>
<html>
<body>
<canvas id=c width=200 height=200></canvas>
<script>
const c=document.getElementById('c'),x=c.getContext('2d'),S=10;
let p=[10,10],d=[1,0],f=[20,20],l=0;
x.fillStyle='#000';x.fillRect(0,0,200,200);
document.onkeydown=e=>{d=[e.key=='ArrowLeft'?-1:0,e.key=='ArrowUp'?0:-1,e.key=='ArrowRight'?1:0,e.key=='ArrowDown'?0:1][e.key.match(/\d/)?0:d]}
function g(){
  let n=[p[0]+d[0],p[1]+d[1]];
  if(n[0]<0||n[0]>=20||n[1]<0||n[1]>=20||p.includes(n)){l++;return}
  p=n;
  if(n[0]==f[0]&&n[1]==f[1]){f=[~~(Math.random()*20),~~(Math.random()*20)]}
  x.fillStyle='#000';x.fillRect(0,0,200,200);
  x.fillStyle='#0f0';p.forEach(i=>x.fillRect(i[0]*S,i[1]*S,S,S));
  x.fillStyle='#f00';x.fillRect(f[0]*S,f[1]*S,S,S);
  setTimeout(g,100);
}
g();
</script>
</body>
</html>
```

**Features:**
- 🐍 Snake moves with arrow keys
- 🍎 Red food spawns randomly
- 💀 Game over on wall/self collision
- Score shown in `l` variable
- Runs at 10fps

**Controls:** Arrow keys to change direction. The snake continues in its current direction if you press an invalid key.
